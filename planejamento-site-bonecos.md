# DOCUMENTO DE DEFINIÇÕES INICIAIS  
## Planejamento do MVP

---

# 1. Visão Geral do Projeto

Este projeto tem como finalidade o desenvolvimento de uma **Loja Virtual de Action Figures**, buscando oferecer uma experiência moderna, intuitiva e acessível aos usuários.

O MVP (Produto Mínimo Viável) contará com funcionalidades principais, como:

- Exibição dos bonecos dos integrantes;
- Visualização detalhada de cada boneco;
- Carrinho de compras simplificado;
- Interface com acessibilidade aplicada.

---

# 2. Escopo do MVP

O MVP da aplicação possuirá os seguintes módulos e funcionalidades:

- Imagem principal dos bonecos dos integrantes;
- Acessório característico de cada boneco;
- Comparação entre a foto original dos integrantes e seus respectivos bonecos.

# 4. Diretrizes de Acessibilidade (A11y)

A acessibilidade será implementada desde o início do desenvolvimento, seguindo boas práticas e recomendações internacionais.

---

## 4.1 Uso de HTML Semântico (HTML5)

Utilização de elementos como `<button>`, `<nav>`, `<main>` e `<article>` para garantir que tecnologias assistivas interpretem corretamente as informações exibidas.

---

## 4.2 Contraste de Cores Adequado

Aplicação de combinações de cores conforme as diretrizes da WCAG, proporcionando melhor legibilidade para usuários com baixa visão.

---

## 4.3 Alternativas Textuais para Imagens

Utilização de atributos `alt` descritivos em todas as imagens importantes da aplicação.

---

## 4.4 Uso Correto de Labels em Inputs

Associação adequada entre elementos `<label>` e campos de formulário, melhorando a usabilidade e acessibilidade.

---

## 4.5 Acessibilidade Durante o Ciclo de Vida do Projeto

A acessibilidade será uma responsabilidade compartilhada entre:

- UX;
- Desenvolvimento;
- QA.

---

## 4.7 Uso de ARIA (quando necessário)

Aplicação de atributos ARIA para complementar o HTML semântico em situações específicas.

---

## 4.8 Estrutura Clara e Organizada

Organização adequada utilizando:

- Títulos hierárquicos (H1 até H6);
- Seções bem estruturadas;
- Conteúdo organizado de forma clara.

---

## 4.9 Testes de Acessibilidade

Realização de validações contínuas utilizando ferramentas como:

- Lighthouse;
- Skynet Technologies.
